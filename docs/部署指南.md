# 部署指南

本文按「从零到能跑第一条龙」的顺序写。第一次部署大约需要 1–3 小时，主要时间花在下载模型和安装依赖上。

> **v1.5.0 起日常启动使用 `AI3D-Print-Flow.exe`**：双击 exe 即可启动控制台，桌面快捷方式也直接指向它。exe 是轻量启动器，仍依赖同目录的 `runtime\node.exe` 和 `app\`，不是单文件内嵌 Node。
>
> **v1.4.0 起默认推荐「一键部署」，但它现在是可选方式**（见第 1.1 节），「手动分步」完整保留。v1.4.0 修复了「`ComfyUI-Easy-Install` 已存在」导致安装器退出的问题，并新增精确同名模型复用与部署后自检。v1.2.0 的 47 项可靠性、安全与恢复优化见 [优化记录-v1.2.0.md](优化记录-v1.2.0.md)。

---

## 0. 部署前先确认

### 0.1 硬件

| 项目 | 最低 | 推荐 |
|---|---|---|
| 系统 | Windows 10 21H2 / Windows 11 x64 | Windows 11 |
| 显卡 | NVIDIA RTX 2060 6 GB | RTX 3060 12 GB / 4060 Ti 16 GB / 4070 Ti Super 16 GB / 4090 / 5080 |
| 内存 | 16 GB | 32 GB+（2K 必须） |
| 磁盘 | 80 GB 空闲 | SSD，100 GB+ |
| 驱动 | 较新的 NVIDIA 驱动 | 最新 Game Ready / Studio |

> 不支持 AMD / Intel 显卡跑完整 TRELLIS.2 流程。AMD 版本在上游仍在开发。

### 0.2 软件

- 本包已内置 Node.js，不需要另装。
- `AI3D-Print-Flow.exe` 使用 .NET Framework 4.x；Windows 10 21H2 / Windows 11 通常已自带，不需要单独安装。
- ComfyUI Easy Install 会自带 Python 3.12 和 Git。
- Blender 需要单独装（控制台可以用 winget 调起安装）。
- CHITUBOX 可选，但你要打印就需要。

### 0.3 路径建议

```text
包体：      D:\AI3D-Print-Flow
ComfyUI：   D:\AI3D\ComfyUI-Easy-Install
工作目录：  D:\AI3D-Print-Flow\workspace
```

避免：

- 路径里有大量中文/特殊符号；
- 把 ComfyUI 装在 `C:\Program Files`（权限问题）；
- 把包体放在 OneDrive 同步目录里跑大模型；
- 直接在 ZIP 里双击（必须先解压）。

## 1. 解压与首次启动

1. 用 7-Zip 或资源管理器解压 ZIP。
2. 进入 `AI3D-Print-Flow` 目录，确认能看到：
   - `AI3D-Print-Flow.exe`
   - `runtime\node.exe`
   - `app\server.mjs`
   - `start.cmd` / `deploy.cmd`（兼容入口）
3. 双击 **`AI3D-Print-Flow.exe`**。这是日常启动入口；想直接进入部署页，也可以双击 `首次部署.cmd`。
4. 会弹出一个命令行窗口并启动本地服务，然后自动打开浏览器：
   ```text
   http://127.0.0.1:17860/
   ```
   如果从 `首次部署.cmd` 进入，会先跑一次命令行环境检测，地址带 `#deploy`。
5. 如果 17860 被占用，端口会自动 +1，命令行窗口会打印实际地址。

> 控制台只监听 `127.0.0.1`，局域网内其他设备访问不到。

## 1.1 一键部署（默认推荐）

### 1.1.1 操作

1. 打开页面「环境部署」。顶部有「一键部署 / 手动分步」两个选项，默认选中「一键部署」；选择会记住。
2. 保持「自动复用本机同名模型」勾选。它只复用文件名和大小精确匹配的权重，同盘用硬链接，不重复占用空间。
3. 需要本地文生图时勾选「同时下载 Qwen 模型（约 25 GB）」；只用 TRELLIS.2 可以不勾。
4. 点「开始一键部署」。
5. 进度面板会显示：
   - 当前阶段（ComfyUI / Torch / TRELLIS.2 / 水密节点与模型 / 工作流 / Qwen / 完成）；
   - 百分比、阶段说明、下载字节、总大小、速度、剩余时间；
   - 安装器运行时间（安装器内部下载用不确定进度动画表示）。
6. 可以点「取消部署」；取消后不会标记为失败。处理完问题再点「继续部署（断点续跑）」。
7. 成功或失败后都会自动运行「部署后自检」。先处理红色阻塞项，再启动 ComfyUI。

> 想自己控制每一步，随时切到「手动分步」；它保留 01–05 的所有按钮。一键部署执行期间不能切换，完成或取消后可切换。

### 1.1.2 自动执行的顺序

```text
1. 检查磁盘空间、安装目录、ComfyUI 是否在运行
2. 若 ComfyUI-Easy-Install 缺少 main.py 或 python_embeded\python.exe，先改名保留
3. 下载并解压 ComfyUI Easy Install
4. 运行官方安装器（Git 已安装时跳过 Git 升级）
5. 验证 ComfyUI\main.py + python_embeded\python.exe
6. 扫描并硬链接本机精确同名的模型（可选，默认开启）
7. 切换 PyTorch 2.8.0 + CUDA 12.8，并验证版本
8. 安装 TRELLIS.2 + Pixal3D 节点
9. 安装 WTiVo/水密节点，AUTO_DL=Y 自动补基础模型
10. 校验 TRELLIS.2 主模型、VAE、DINOv3、BiRefNet、形状编码器
11. 写入 4 个 PixelArtistry 工作流
12. 可选：下载 Qwen-Image 2.1 的 4 个模型
```

每一步都是幂等的：已经完成的步骤会跳过，因此失败或取消后可以直接重试。

### 1.1.3 断点续跑、目录与模型复用

- 下载中的文件保留 `.part`，下次用 HTTP Range 续传；连接/流中断最多自动重试 5 次，并带 30 秒连接超时、60 秒停滞超时。
- `.part.json` 记录断点对应的 URL、ETag 和总大小；远端文件变化时会自动丢弃旧断点，避免拼错文件。
- `ComfyUI-Easy-Install` **只有同时存在** `ComfyUI\main.py` 和 `python_embeded\python.exe` 才算完整。缺任意一个（尤其只有 `main.py`、`python.exe` 被隔离）时，控制台会先改名为：
  ```text
  ComfyUI-Easy-Install.incomplete-<时间戳>
  ```
  不会删除原目录，方便你从杀软隔离区恢复或排查。官方安装器看到同名目录会直接退出，所以必须先移走。
- 改名失败通常表示目录或 `python.exe` 正被占用、权限不足或杀软正在扫描。先关闭 ComfyUI、所有 `python.exe` 和打开该目录的资源管理器窗口，检查火绒 / Windows Defender 的隔离区，把 `D:\AI3D` 加入白名单，再重试。
- 「自动复用本机同名模型」只接受**文件名和大小匹配**的权重，扫描当前 ComfyUI、常见安装目录和 Hugging Face 缓存。同盘使用硬链接，源文件保持原位，不额外占用空间；跨盘或 FAT/exFAT 无法硬链接时只提示手动复制，不会静默复制几十 GB。
- Ollama（GGUF）、Hugging Face 聊天模型和 Stable Diffusion 检查点与 Qwen-Image 2.1 / TRELLIS.2 架构不同，**不会**被误复用；自检会列出本机模型并解释原因。
- 如果 ComfyUI 正在运行，安装 Torch/节点前会停止并提示：
  ```text
  请先关闭 ComfyUI 窗口，再点一键部署。
  ```
  这是因为安装器会替换 Python 包，运行中的 ComfyUI 会占用文件。

### 1.1.4 部署后自检

一键部署结束（成功或失败）后会自动运行「部署后自检」，也可以随时点「重新自检」：

- 检查 ComfyUI 是否完整、缺 `main.py` 还是缺 `python_embeded\python.exe`；
- 检查 Python 3.12 / PyTorch 2.8.0 / CUDA 12.8；
- 检查 TRELLIS.2、PixelArtistry 节点与工作流；
- 检查必需/可选模型，指出缺哪个文件、应放到哪个目录；
- 检查磁盘、内存、GPU、Blender、CHITUBOX 与 ComfyUI 服务；
- 列出本机 Ollama / Hugging Face 模型，并判断是否有精确同名的可复用权重；
- 按 `fail / warn / info` 分级，每项带稳定代码、原因和 `FIX` 处理步骤。「复制报告」可把结果复制为文本，方便排查记录。

自检通过只代表组件齐全，仍建议实际跑一条工作流验证显存和输出。

### 1.1.5 日志与失败处理

- 一键部署面板：展开日志，看最后 120 行。
- 部署后自检：红色 `fail` 先处理；`warn` 影响功能或体验；`info` 可能只是可选组件或 ComfyUI 未启动。点「复制报告」保存完整结论。
- 如果日志出现 `WARNING: 'ComfyUI-Easy-Install' folder already exists!`，说明官方安装器看到了旧目录。v1.4.0 会先检查并改名不完整目录；若仍出现，查看自检的 `COMFY_INCOMPLETE`，按提示关闭占用并检查杀软隔离区。
- 服务日志：`logs/server.log`，包含全局异常、500 请求和慢请求；超过 5 MB 会轮转为 `server.log.1`–`.3`。
- 健康检查：<http://127.0.0.1:17860/api/health>，返回版本、PID、Node 版本、内存和正在运行的任务数。
- 诊断快照：<http://127.0.0.1:17860/api/diagnostics>，包含版本、路径、最近任务和日志尾部；页面连接横幅里的「复制诊断信息」会自动整理并复制，剪贴板不可用时下载 `ai3d-diagnostics-*.txt`。
- 如果页面提示「本地服务连接中断」或 `Failed to fetch`，先确认启动窗口还在运行；关闭后双击 `AI3D-Print-Flow.exe` 或桌面快捷方式，再刷新页面。仍失败时点「复制诊断信息」，并查看 `server.log` 和浏览器 F12 Console。
- 重复双击快捷方式时会先探测已有服务：同版本已在运行就直接打开现有页面，不会另开一个 17861 控制台。
- 控制台只监听 `127.0.0.1`，并校验 Host/Origin；跨站请求返回 403，非 JSON 操作请求返回 415。这是本地服务的安全边界，不是故障。

### 1.1.6 一键部署不包含什么

- Blender 和 CHITUBOX 仍按第 5、6 节单独安装（许可证和安装路径不适合静默处理）。
- 不会自动启动 ComfyUI；完成后点页面「启动 ComfyUI」。
- 不会自动替你点 ComfyUI 里的 Run，工作流仍由你选择图片和参数。

## 2. 手动安装 ComfyUI Easy Install（备选）

### 2.1 手动页面操作

在「环境部署」第 01 张卡片：

1. 点 **「下载并解压」**。
2. 控制台会从 GitHub Releases 下载 `ComfyUI-Easy-Install.zip` 到 `installRoot`，并解压。
3. 点 **「运行安装器」**。
4. 如果目标 `ComfyUI-Easy-Install` 已存在但缺少 `ComfyUI\main.py` 或 `python_embeded\python.exe`，控制台会先把它改名为 `.incomplete-<时间>`，再打开安装器。
5. 会弹出一个独立的命令行窗口，运行 `ComfyUI-Easy-Install.bat`。

### 2.2 安装器里怎么选

不同版本的 Easy Install 向导文字会变，但原则不变：

- 安装路径选 **`D:\AI3D`**（或你确定的短路径）；
- 让安装器创建 `ComfyUI-Easy-Install` 子目录；
- Python 用自带的 3.12；
- PyTorch 选 **2.8.0 + CUDA 12.8**（如果向导让你选）；
- Git 用自带的，或允许它调用系统 Git；
- 其他选项保持默认；
- 等待依赖安装完成。

> 如果向导里没有 2.8.0 + CUDA 12.8，先完成安装，再用第 3 步的 Torch 切换脚本。

### 2.3 安装完成后

目录应该长这样：

```text
D:\AI3D\
└─ ComfyUI-Easy-Install\
   ├─ ComfyUI\
   │  ├─ main.py
   │  ├─ custom_nodes\
   │  └─ models\
   ├─ python_embeded\
   │  └─ python.exe
   ├─ Add-ons\
   ├─ Start ComfyUI.bat
   └─ ComfyUI-Easy-Install.bat
```

回到控制台点「重新检查」。`ComfyUI 安装` 应该变成「已就绪」。

### 2.4 手动安装（页面下载失败时）

1. 打开 <https://github.com/Tavris1/ComfyUI-Easy-Install/releases>。
2. 下载最新的 `ComfyUI-Easy-Install.zip`。
3. 解压到 `D:\AI3D`。
4. 双击 `ComfyUI-Easy-Install.bat`，按向导安装。
5. 在控制台「设置」里把 `ComfyUI 根目录` 指到 `D:\AI3D\ComfyUI-Easy-Install`。

## 3. 切换 Torch 2.8 并安装 TRELLIS.2

### 3.1 为什么必须这组版本

WTiVo 的预编译后端是按下面这组版本编译的：

```text
Python 3.12
PyTorch 2.8.0
CUDA 12.8
```

版本不对，节点会报：

- `DLL load failed`
- `CUDA error: no kernel image is available`
- `undefined symbol`
- 或直接崩溃。

### 3.2 页面操作

第 02 张卡片：

1. 点 **「切换 Torch 2.8」**。
2. 会打开 Easy Install 的 Add-ons 里的 Torch 2.8 脚本。按提示确认，等待安装完成。
3. 点 **「安装 TRELLIS.2」**。
4. 会打开 Trellis2 安装脚本。它会下载：
   - ComfyUI-Trellis2 节点；
   - TRELLIS.2 / Pixal3D 模型；
   - 相关依赖。
5. 等待脚本结束。模型下载可能很久，网络差时优先用有线/代理。

### 3.3 验证

在控制台点「重新检查」，或者用命令行：

```bat
runtime\node.exe app\cli.mjs check
```

应该看到：

```text
[OK] ComfyUI 安装: D:\AI3D\ComfyUI-Easy-Install
[OK] Python / PyTorch / CUDA: Python 3.12.x · Torch 2.8.0... · CUDA 12.8
[OK] ComfyUI-Trellis2 节点: ...
[OK] TRELLIS.2 主模型: ...
```

如果 Torch 还是 2.6/2.7，回到 Add-ons 再跑一次 Torch 2.8 脚本。

## 4. 安装 PixelArtistry 水密节点

### 4.1 页面操作

第 03 张卡片：

1. **先完全关闭 ComfyUI**（包括命令行窗口）。
2. 点 **「运行节点安装器」**。
3. 控制台会把官方 `watertightMeshes_win_installer.bat` 复制到：
   ```text
   D:\AI3D\ComfyUI-Easy-Install\Add-ons\PixelArtistry-Watertight-Installer.bat
   ```
   然后在新窗口运行。
4. 安装器会：
   - 检查 Python/PyTorch/CUDA/GPU；
   - 下载 WTiVo、Quad Reconstruct、LODTailor、Fast Merge、Memory Cleaner、CuMesh Decimate 等节点；
   - 按显卡选择 WTiVo 构建；
   - 安装依赖；
   - 跑一次 GPU 水密测试；
   - 安装 4 个工作流；
   - 检查模型；
   - 查找 Blender。
5. 看到汇总只有 `[OK]` 才继续。

### 4.2 只写入工作流

如果节点已经装好，只缺工作流，点 **「仅写入工作流」**。它会把 `vendor/pixelartistry/workflows/` 下的 4 个 JSON 复制到：

```text
D:\AI3D\ComfyUI-Easy-Install\ComfyUI\user\default\workflows\PixelArtistry\
```

### 4.3 手动安装

1. 打开 <https://github.com/PixelArtistry/PixelArtistry-Watertight-Meshes>。
2. 下载 `watertightMeshes_win_installer.bat`。
3. 放进 `ComfyUI-Easy-Install\Add-ons`。
4. 关闭 ComfyUI，双击运行。
5. 按提示补全缺失模型。

## 5. 安装 Blender

### 5.1 winget（推荐）

第 04 张卡片点 **「winget 安装」**。控制台会执行：

```bat
winget install --id BlenderFoundation.Blender --exact --silent --accept-package-agreements --accept-source-agreements
```

安装完成后点「重新检查」，控制台会自动找到：

```text
C:\Program Files\Blender Foundation\Blender 5.x\blender.exe
```

### 5.2 官网安装

点「官网下载」，安装到默认路径。然后在控制台「设置」里填：

```text
C:\Program Files\Blender Foundation\Blender 5.2\blender.exe
```

### 5.3 便携版（可选）

如果无头模式被插件干扰：

1. 下载 Blender ZIP；
2. 解压到 `D:\Tools\Blender`；
3. 在 `blender.exe` 旁边新建空文件夹 `portable`；
4. 把工作流里的 Blender 路径指到 `D:\Tools\Blender\blender.exe`。

> 路径不要带首尾双引号。这是视频里特别强调的坑。

## 6. 安装 CHITUBOX

1. 点第 05 张卡片的「官网下载」：<https://www.chitubox.com/en/download/chitubox-free>。
2. 安装后控制台会自动检测 `C:\Program Files\CHITUBOX\CHITUBOX.exe`。

## 7. 部署完成检查

在控制台点「部署后自检」→「开始自检」，这是最完整的检查；也可以点「重新检查」看环境卡片，或用命令行：

```bat
runtime\node.exe app\cli.mjs check
```

自检报告会直接告诉你缺 `ComfyUI\main.py` 还是 `python_embeded\python.exe`、缺哪个模型、Torch 版本是否正确，以及本机是否有可复用的同名权重。

### 必须全绿

- [ ] 部署后自检没有红色阻塞项（`COMFY_INCOMPLETE`、`TORCH_MISMATCH`、`NODES_MISSING` 等）
- [ ] Windows 10/11 x64
- [ ] NVIDIA 显卡 + 驱动
- [ ] 内存 ≥ 16 GB（2K 建议 32 GB）
- [ ] 安装盘 ≥ 45 GB（基础流程；勾选 Qwen 建议 110 GB 以上；一键部署预检基础 30 GB / 勾选 Qwen 55 GB）
- [ ] ComfyUI 安装（同时有 `ComfyUI\main.py` 与 `python_embeded\python.exe`）
- [ ] Python 3.12 / Torch 2.8.0 / CUDA 12.8
- [ ] ComfyUI-Trellis2 节点
- [ ] TRELLIS.2 主模型、形状 VAE、纹理 VAE、DINOv3、BiRefNet、形状编码器
- [ ] PixelArtistry 节点（WTiVo、Quad、LODTailor、Fast Merge 等）
- [ ] PixelArtistry 工作流 ≥ 1
- [ ] Blender

### 可选/警告

- CHITUBOX 未安装：只影响切片，不影响生成。
- Qwen 模型未安装：不影响 TRELLIS.2，但你不能在本地文生图。
- ComfyUI 服务未启动：点「启动 ComfyUI」。

## 8. 跑通第一条龙

### 8.1 启动 ComfyUI

控制台点「启动 ComfyUI」，或在 Easy Install 根目录双击 `Start ComfyUI.bat`。等待浏览器打开 `http://127.0.0.1:8188`。

### 8.2 生成图片

1. 控制台填主体描述，例如：
   ```text
   一条盘踞在圆形底座上的东方龙，鳞片清晰
   ```
2. 风格提示词保持默认，或按你的主体改。
3. 选 2K（显存不够选 1.5K）。
4. 点「生成提示词并写入工作流」。
5. 打开 ComfyUI → **Workflows → PixelArtistry → AI3D_Qwen_2k_*.json**。
6. 点 Run，等待出图。
7. 在 `ComfyUI/output/AI3D/Qwen_2k` 里选图。

### 8.3 图片转水密网格

1. 把选中的图拖进控制台「图片 → 水密 3D 网格」。
2. 选 1.5K 或 2K。
3. 点「注入图片并生成水密工作流」。
4. ComfyUI 打开 `AI3D_1.5k_*.json` 或 `AI3D_2k_*.json`。
5. 检查紫色 **Blender path** 节点：
   - 应该是 `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`；
   - 不能带引号。
6. 点 Run，等待 10–12 分钟。
7. 在 3D 预览里检查正面/背面/底部。
8. 如果结果满意，确认 `Save3DAdvanced` 已保存 GLB。

### 8.4 导入 GLB

回到控制台，点「导入 ComfyUI 最新 GLB」。控制台会从 `ComfyUI/output/3d` 递归找最新的 `.glb`，复制到 `workspace/glb`。

也可以手动拖 GLB 进页面。

### 8.5 Blender 后处理

1. 目标高度填 80 mm（或你的平台尺寸）。
2. 修复模式：
   - **自动**：先补洞，失败再体素重建；
   - **仅补小洞**：保留细节，适合小破洞；
   - **体素重建**：强力，适合大破洞/薄壳，但可能变厚；
   - **不修复**：只做清理/缩放。
3. 减面比例：先 0，确认能切片再考虑减。
4. 勾选「只保留主部件与占比 ≥1% 的独立部件」。
5. 点「运行 Blender 后处理」。
6. 看结果：
   - 水密：是/否；
   - 尺寸；
   - 三角面；
   - 体积；
   - 边界边/非流形边。
7. 下载 STL。

### 8.6 CHITUBOX

1. 启动 CHITUBOX，导入 STL。
2. 检查尺寸。若模型仍很小，比例 100 → 10000。
3. 抬高 2–3 mm。
4. 加 Light 支撑，Cross/Branch。
5. 底座高度 2.0 mm。
6. 关闭平台接触形状。
7. 切片，逐层检查。
8. 打印、清洗、拆支撑、UV 固化。

## 9. 配置说明

配置文件：`config/config.json`

```json
{
  "version": 1,
  "installRoot": "D:\\AI3D",
  "comfyuiRoot": "D:\\AI3D\\ComfyUI-Easy-Install",
  "blenderPath": "C:\\Program Files\\Blender Foundation\\Blender 5.2\\blender.exe",
  "chituboxPath": "C:\\Program Files\\CHITUBOX\\CHITUBOX.exe",
  "workspaceDir": "",
  "preset": "1.5k",
  "targetHeightMm": 80,
  "repairMode": "auto",
  "decimateRatio": 0,
  "port": 17860,
  "comfyUrl": "http://127.0.0.1:8188",
  "lastImage": "",
  "lastGlb": "",
  "lastStl": "",
  "lastReport": ""
}
```

| 键 | 说明 |
|---|---|
| `installRoot` | ComfyUI 安装根目录，Easy Install ZIP 也下到这里 |
| `comfyuiRoot` | 含 `ComfyUI\main.py` + `python_embeded` 的目录 |
| `blenderPath` | `blender.exe` 完整路径，不带引号 |
| `chituboxPath` | CHITUBOX 完整路径 |
| `workspaceDir` | 留空用包内 `workspace` |
| `preset` | 默认 1k / 1.5k / 2k |
| `targetHeightMm` | 后处理目标高度，0 表示不缩放 |
| `repairMode` | auto / fill / voxel / none |
| `decimateRatio` | 0–1，0 不减面 |
| `port` | 控制台端口 |
| `comfyUrl` | ComfyUI 地址 |

改完保存，控制台会自动重新检测。也可以直接编辑 JSON 后重启。

## 10. 启动方式与命令行

### 10.1 双击

- `AI3D-Print-Flow.exe` ← 日常启动（推荐；桌面快捷方式指向它）
- `首次部署.cmd` / `deploy.cmd` ← 直接进入部署页
- `创建桌面快捷方式.cmd` / `create-shortcut.cmd`
- `启动 AI3D 打印工作流.cmd` / `start.cmd` ← 兼容入口；存在 exe 时优先转调 exe

### 10.2 命令行

日常命令可以直接用启动器（推荐）：

```bat
AI3D-Print-Flow.exe check
AI3D-Print-Flow.exe start --deploy
AI3D-Print-Flow.exe start --no-open
AI3D-Print-Flow.exe start --port 17870
AI3D-Print-Flow.exe postprocess --input "D:\AI3D\dragon.glb" --height 80 --repair auto --decimate 0
AI3D-Print-Flow.exe workflow list
AI3D-Print-Flow.exe workflow pixel --image "D:\AI3D\dragon.png" --preset 1.5k
AI3D-Print-Flow.exe workflow qwen --prompt "一条盘踞在圆形底座上的东方龙" --preset 2k --seed 123
```

启动器无参数时等价于 `start`；`--deploy` / `--no-open` / `--port` 等服务器参数会自动补上 `start`。排错时也可以直接调用内置 Node，例如 `runtime\node.exe app\cli.mjs check`，效果相同。

## 11. 桌面快捷方式

### 11.1 自动

双击 `创建桌面快捷方式.cmd`，或控制台底部点「创建桌面快捷方式」。

脚本会：

1. 找到包体根目录的 `AI3D-Print-Flow.exe`（缺失时先调用 `scripts\build-launcher.ps1` 编译）；
2. 在桌面创建 `AI3D 打印工作流.lnk`；
3. 把快捷方式目标设为该 exe，不带参数，工作目录设为包体根目录，图标从 exe 读取。

> 快捷方式的目标是包体根目录里的 `AI3D-Print-Flow.exe`，所以右键快捷方式 → **打开文件所在的位置** 会直接进入包体根目录。移动包体后，需要重新运行一次创建脚本。exe 不是单文件应用，仍需要同目录的 `runtime\node.exe` 和 `app\`。

### 11.2 手动

1. 右键 `AI3D-Print-Flow.exe` → **发送到 → 桌面快捷方式**。
2. 右键快捷方式 → **属性**：
   - 目标：`"D:\AI3D-Print-Flow\AI3D-Print-Flow.exe"`
   - 起始位置：`D:\AI3D-Print-Flow`
   - 图标：`D:\AI3D-Print-Flow\AI3D-Print-Flow.exe`
3. 确定。

### 11.3 固定到任务栏/开始菜单

右键快捷方式 → **固定到任务栏** 或 **固定到开始屏幕**。

## 12. 移动、备份、卸载

### 12.1 移动包体

包体可以整体移动，但 `config/config.json` 里的绝对路径不会自动跟着变。移动后：

1. 打开「设置」，把 ComfyUI / Blender / CHITUBOX 路径改成新路径；
2. 或删除 `config/config.json`，让控制台重新检测；
3. `workspace` 里的图片/模型也会跟着包体走；
4. 重新运行 `创建桌面快捷方式.cmd`，因为快捷方式里保存的是 exe 的绝对路径。

ComfyUI 本身在 `D:\AI3D`，不受包体移动影响。

### 12.2 备份

- 工作流：`ComfyUI\user\default\workflows\PixelArtistry`
- 自定义节点：`ComfyUI\custom_nodes`
- 模型：`ComfyUI\models`
- 生成结果：`ComfyUI\output`
- 本控制台工作区：`workspace`

### 12.3 卸载

1. 关闭控制台和 ComfyUI；
2. 删除包体目录；
3. 如不再需要，删除 `D:\AI3D`（会删掉 ComfyUI 和模型）；
4. 删除桌面快捷方式。

## 13. 常见部署问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击 `AI3D-Print-Flow.exe` 没反应 | 文件被 SmartScreen/杀软拦截，或缺少 .NET Framework 4.x | 右键 → 属性 → 解除锁定；把包体目录加入白名单；Windows 10 21H2 / 11 通常已带 .NET 4.x |
| 启动器提示「找不到内置 Node 运行时」 | 只复制了 exe，`runtime\node.exe` 缺失 | 重新解压完整包；exe 必须和 `runtime\`、`app\` 放在同一目录 |
| 浏览器打不开 | 端口被占用/防火墙 | 看命令行窗口实际地址；换 `--port 17870` |
| 页面提示 `Failed to fetch` | 本地服务已停止/被防火墙拦截/启动窗口被关闭 | 确认启动窗口还在；重新双击 `AI3D-Print-Flow.exe` 或桌面快捷方式后刷新。仍失败看 `logs/server.log` 和浏览器 F12 Console |
| 一键部署停在「连接 GitHub」 | GitHub 网络慢/被拦截 | 等自动重试；或手动下载 ZIP 放到 `installRoot`，再点继续 |
| 一键部署提示 ComfyUI 正在运行 | 8188 仍有 python 进程 | 关闭 ComfyUI 窗口；任务管理器结束 `python.exe` 后重试 |
| 一键部署提示目录不完整 | 上次安装被中断 | 正常点「继续部署」；控制台会自动改名旧目录，也可手动处理 |
| 一键部署后 Qwen 模型仍缺失 | 未勾选或下载中断 | 点「仅下载 Qwen 模型」；支持断点续传 |
| `找不到内置 Node 运行时` / `Node.js runtime was not found` | `runtime\node.exe` 丢失 | 重新解压；或安装 Node 20+ 后使用 `start.cmd` 兼容入口 |
| ComfyUI 下载失败 | GitHub 网络 | 手动下载 ZIP，解压到 `installRoot` |
| 安装器一闪而过 | 路径带空格/中文，或没在 Add-ons 里 | 换短路径，按官方步骤放 Add-ons |
| 安装器提示 ComfyUI 正在运行 | 进程没退 | 任务管理器结束 `python.exe` / ComfyUI 窗口 |
| Torch 版本不对 | 跑了系统 Python | 用 Easy Install 的 Torch 2.8 脚本，不要用系统 Python |
| WTiVo `DLL load failed` | CUDA/PyTorch 不匹配 | 回到 3.12 / 2.8.0 / 12.8 |
| 模型缺失 | HF 下载失败 | 看安装器汇总，按文件名手动下载到 `ComfyUI\models\...` |
| Blender 找不到 | 未装/路径错 | 设置里填 `blender.exe` 完整路径，去掉引号 |
| 后处理报 Blender 退出码 2 | Python 脚本异常 | 看任务栏日志；确认 Blender 5.x、路径无引号 |
| STL 不水密 | 原网格破洞/体素太粗 | 换种子、提高 `lambda_fill`、体素重建 |
| 控制台设置保存后没生效 | 缓存 | 点「重新检查」或重启控制台 |

更多参数与报错见 [参数与排错.md](参数与排错.md)。

## 14. 安全与隐私

- 控制台只监听 `127.0.0.1`，请求会校验 Host，局域网不能访问。
- 图片和模型只在本机处理，不上传。
- 但安装器会从 GitHub / Hugging Face 下载节点和模型，这是网络请求。
- 不要在不信任的目录运行来历不明的 `config.json` 或工作流。
- 树脂打印注意通风、手套、护目镜，按树脂厂家说明处理废液。
