## 2. 核心概念

### 2.1 什么是水密（watertight）

一个可切片的实体网格，理想状态下应满足：

- 每条边恰好被两个三角面共享；
- 没有边界边（boundary edge）；
- 没有非流形边（non-manifold edge）；
- 没有悬浮面片、内外翻转面、重复顶点造成的“假裂缝”；
- 网格围成一个明确的闭合体积。

切片软件需要判断“哪里是实体内部、哪里是外部”。有破洞或悬浮面时，切片会出现空洞、缺层、错误支撑，甚至整层失败。

视频里用 Blender 的 **3D Print Toolbox → Check All** 验证，结果是 **0 条边界边**，并展示内部视图没有悬浮几何体。

### 2.2 为什么“看起来闭合”不等于水密

GLB/OBJ 为了 UV 展开，可能把同一个位置拆成多个顶点。导入 Blender 时如果不合并，UV 接缝会显示成开放边。PixelArtistry README 特别提醒：导入带纹理的低模时勾选 **Merge Vertices**，否则会把 UV 接缝误判为破洞。

### 2.3 代理点（proxy points）与体素重建

WTiVo 不是简单“补洞”，而是用稀疏体素/代理点场重新表达表面，再重建出闭合网格。代理点越多：

- 细节保留越好；
- 显存/内存占用越高；
- 网格面数越大；
- 后续 LODTailor 减面压力越大。

官方对照：

| 显存 | WTiVo 分辨率 | 代理点 | 说明 |
|---|---|---|---|
| 6 GB | 1024 | 不够就继续降 | 低显存 |
| 8 GB+ | 1536 | 12,000,000 | 工作流 01/02；WTiVo 约 2 分钟，约 6 GB 内存 |
| 16 GB+ | 2048 | 25,000,000 | 工作流 01b；WTiVo 约 3.5 分钟，约 11 GB 内存 |

### 2.4 为什么 2K 要绕过 Quad Reconstruct

官方 README 的解释很关键：

- 2K 下如果保留 Quad Reconstruct 的 2048 输出，WTiVo 网格会膨胀到约 **8500 万面**，内存约 **17 GB**；
- LODTailor 再把这种网格减面时，容易破坏水密性；
- 所以 2K 工作流把 Quad Reconstruct 设为 **bypass（mode 4）**；
- 直接用 25M 代理点，得到约 **4300 万面** 的水密网格，整条链路保持水密。

这也解释了为什么 2K 不是“把 1.5K 参数乘 1.33”这么简单。

### 2.5 LODTailor 与 Fast Merge

- **LODTailor**：在 Blender 里做网格精简/裁剪，目标是在减面的同时保持水密。工作流默认面数上限约 600 万，相对体素 0.001。
- **Fast Merge by Distance**：焊接重复顶点，消除“位置相同但索引不同”的假开放边。
- **Quad Reconstruct**：清理原始网格的拓扑，让后续体素化更稳定；2K 下按上面的原因绕过。

### 2.6 单视图 vs 多视图

- 单视图：只给一张正面图，背面靠模型先验“猜”。视频里龙的背面整体可用，但天空/背景边缘偶尔会带出小碎块。
- 多视图：用 Qwen-Image 2.1 编辑出 4 个视角，再送进 TRELLIS.2 的多视图模式。视频演示了该工作流，但也明确说：多视角有时对不齐，会出现不圆滑、变形；可以尝试调整焦距条件（视频里提到 20 是个不错的数值）。

本包只内置官方仓库的 4 个单图工作流（水密 1.5K、水密 2K、图生游戏资产、网格生游戏资产），没有内置多视图工作流。单视图主流程不受影响。

### 12:30–14:30 1K / 1.5K / 2K 对比与水密检查

作者分别用 1024、1536、2K 跑龙：

- 2K 细节最多，鳞片、面部结构更清楚；
- 1.5K 与 2K 的差距没有想象中大，多数时候 1.5K 更划算；
- 1K 明显丢细节，眼睛周围、细小区域会被抹平，但简单角色仍够用；
- 2K 文件更大、更吃显存/内存。

他用 Blender 的 **3D Print Toolbox → Check All** 检查 1.5K 龙：

- **0 条边界边**；
- 真正水密；
- 内部视图没有悬浮面片/悬浮几何体。

### 14:30–16:00 Blender 手工清理

这是视频里最重要的手工步骤：

1. `File → Import → glTF 2.0 (.glb)` 导入；
2. 选中模型，进入 **Object Mode**，再进 **Edit Mode**；
3. 按 **P** → **Separate by Loose Parts**；
4. 模型会被拆成多个松散块；视频里大约 **13 个**；
5. 隐藏主模型，选中所有小碎块；
6. 按 **X** 删除；
7. 全选主模型，**Join** 合并；
8. 回 **Object Mode**；
9. `File → Export → STL`；
10. 保存到打印文件夹；
11. **务必勾选 Selection Only**，否则可能把地面/辅助对象一起导出；
12. **Scale 保持 1.0**。

### 16:00–17:30 CHITUBOX：比例、支撑、切片

1. 打开 CHITUBOX，点加号导入 STL；
2. 模型默认非常小；
3. 把比例 **100 改成 10000**（放大 100 倍），模型才到真实尺寸；
4. 视频里同时摆了 1K 和 1.5K 两个版本；
5. 进入支撑编辑；
6. 支撑类型改成 **Cross / Branch**，让支撑共享、减少单独支撑；
7. 主要用 **Light** 支撑（微缩模型）；
8. 高级设置里 **底座高度 2.0**；
9. 关闭自动抬升；
10. **平台接触形状选“无”**，避免底部多出几何体；
11. 切片；
12. 发送到光固化打印机。

### 17:30–18:00 打印与后处理

- 打印约 **4 小时**；
- 用清洗机清洗；
- 在 UV 固化站里固化；
- 对比 1K / 1.5K / 2K 最终成品；
- 作者总结：2K 细节最好，但 1.5K 往往更划算；1K 适合简单角色或低显存。

### 5.2 TRELLIS.2 / WTiVo

| 参数 | 1K | 1.5K | 2K |
|---|---|---|---|
| TRELLIS.2 上采样 | 1024 | 1536 | 2048 |
| WTiVo 输入/输出分辨率 | 1024 | 1536 | 2048 |
| 代理点 | 8,000,000 | 12,000,000 | 25,000,000 |
| Quad Reconstruct | 启用 | 启用 | **bypass（mode 4）** |
| 预估网格 | 较低 | 中等 | 约 4300 万面 |
| 显存 | 6–8 GB | 8–16 GB | 16 GB+ |
| 内存 | 16 GB | 16–32 GB | 32 GB+ |

`lambda_fill`（WTiVo 补洞强度）默认 **20**：

- 小洞：10–20；

## 6. 提示词公式

视频没有给出完整提示词原文，但给了公式。可以写成：

```text
[主体] + [姿态/构图] + [材质/细节] + [一体化底座] + [干净背景/无文字] + [适合 3D 打印的紧凑轮廓]
```

本工具默认拼接：

```text
<你的主体描述>, miniature statue, highly detailed scales, dynamic pose,
compact single subject, integrated circular base, clean silhouette,
neutral background, no text, no watermark, designed for 3D printing
```

示例：

```text
一条盘踞在圆形底座上的东方龙，鳞片清晰，动态姿态，
微缩雕像，单一紧凑主体，一体化圆形底座，干净轮廓，
中性背景，无文字，无水印，适合 3D 打印
```

建议：

- 主体尽量单一，避免多个角色互相穿插；
- 底座和主体连成一体，减少悬浮件；
- 避免细如发丝的独立结构；
- 背景干净，最好纯色/中性；
- 不要文字、logo、水印；
- 正面视角、轮廓清楚；
- 生成多张，挑结构最完整的一张。

## 7. 常见问题与注意事项

### 7.1 生成后有洞 / 不水密

1. 先换种子重跑（结构种子默认 randomize）；
2. 提高 WTiVo 的 `lambda_fill`（小洞 10–20，大洞 30–40）；
3. 用本控制台的「体素重建」修复；
4. 仍不行就在 Blender 里手动补洞；
5. 检查是不是 UV 接缝被误判：导入 GLB 时勾选 Merge Vertices。

### 7.2 2K 显存/内存不足

- 重启 ComfyUI，关闭浏览器、游戏、其他 AI 程序；
- 确认没有同时跑 Qwen 和 TRELLIS.2；
- 降到 1.5K；
- 2K 需要 16 GB+ 显存和 32 GB+ 内存，不是“有 16 GB 就一定稳”。

### 7.3 Blender 报错 / 找不到路径

- 路径不要带首尾双引号；
- 用 `blender.exe` 完整路径；
- 干净安装，避免 Auto-Rig Pro、PolyQuilt 等插件；
- 可以下载 Blender ZIP，在 `blender.exe` 旁建空文件夹 `portable`，做成便携版；
- 确认 Blender 版本 4.2+，推荐 5.x。

### 7.4 STL 导入 CHITUBOX 后很小

- Blender 的 1 单位没有毫米语义；
- 视频做法：STL 按 1.0 导出，CHITUBOX 里比例 100 → 10000；
- 本控制台默认按目标高度 80 mm 缩放，通常不需要再改；
- 若仍小，看后处理报告里的 `dimensionsMm`，确认缩放是否生效。

### 7.5 多视图变形

- 多视角没对齐时会出现不圆滑、局部变形；
- 尝试调整焦距条件（视频提到 20）；
- 换更简单、更对称的主体；
- 单视图 + 换种子往往更稳。

### 7.6 支撑与打印

- 微缩模型用 Light 支撑；
- Cross/Branch 共享支撑，减少接触点；
- 底座高度 2.0 mm；
- 关闭平台接触形状；
- 大模型空心 2–3 mm，最低处开 2 个排液孔；
- 切片后逐层检查岛；
- 树脂有毒性/气味，戴手套、通风、按树脂说明清洗和固化。

### 7.7 其他

- 安装器提示 ComfyUI 还在运行：先完全关闭 ComfyUI 再跑；
- 安装器汇总不是全 `[OK]`：不要继续，先解决缺失模型/节点；
- 模型下载慢：GitHub/Hugging Face 网络问题，重试或手动下载到对应目录；
- 路径尽量短、避免中文/空格，尤其是 ComfyUI 安装路径。

## 9. 给第一次尝试的人的建议

1. 先按官方 1.5K 工作流跑通一条龙，不要一上来就 2K。
2. 用简单、对称、单主体的模型练手（小雕像、动物、头像）。
3. 每次只改一个变量：种子、提示词、代理点、lambda_fill。
4. 生成图先看轮廓，再看细节；轮廓不好，3D 一定不好。
5. 3D 结果先看背面和底部，再看正面。
6. Blender 里先删碎块，再补洞，最后缩放。
7. CHITUBOX 里先确认尺寸，再加支撑；尺寸错了，支撑全白做。
8. 打印前先切片预览逐层检查，不要直接打印。
